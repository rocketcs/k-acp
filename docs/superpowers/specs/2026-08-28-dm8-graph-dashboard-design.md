# DM8 电力物资知识图谱驾驶舱设计

## 目标

将 `docs/ontology/dm8-graph-demo-cn.html` 做成一个稳定的本地知识图谱渲染器。页面结构、视觉样式和交互逻辑固定；后续每次查询只提供新的图谱 JSON 数据，不修改 HTML 文件。

## 视觉方向

采用“电力调度驾驶舱”：深海军蓝背景、青色电网辅助线、橙色仓库节点、绿色库存节点、蓝色物资节点，并用紫色供应商、红色项目、黄色区域区分实体类型。页面使用宽屏三栏布局：左侧查询摘要，中部图谱，右侧节点详情。

## 数据契约

页面接受统一 JSON：

```json
{
  "title": "太原供电公司物资仓库",
  "subtitle": "DM8 · MOCK_APP · 查询子图",
  "stats": {"nodeCount": 42, "edgeCount": 81, "amount": 6297424034.41},
  "nodes": [{"id": "...", "label": "...", "kind": "仓库", "properties": {}}],
  "edges": [{"source": "...", "target": "...", "label": "包含库存"}]
}
```

数据加载顺序固定为：

1. `?data=<JSON 文件地址>`：加载外部查询结果；
2. `window.__GRAPH_DATA__`：嵌入式调用方注入结果；
3. 页面内置的最小示例数据：离线打开时仍可展示。

因此同一个 HTML 可以渲染不同仓库、设备类别、供应商或项目查询结果。

## 页面组件

- 顶部状态栏：页面标题、数据来源、更新时间、连接状态。
- 左侧摘要：节点数、关系数、库存金额、查询路径和实体类型图例。
- 中央图谱：ECharts 力导向布局，支持缩放、平移、拖拽、悬停邻接高亮和点击选中。
- 右侧详情：选中节点的中文类型、名称、标识和业务属性；未选择节点时显示查询说明。
- 底部提示：数据契约、刷新方式和中文关系约定。

## 中文约束

节点类型、关系名称、属性显示名全部使用中文。业务编码（例如 `WH0000004`、`INV000019683`、`KYN61-40.5`）原样保留，作为追溯标识。

## 错误处理

- 外部 JSON 加载失败：保留页面骨架，显示失败原因，并回退到内置示例。
- 节点或关系字段缺失：忽略无效记录，不阻断其他图谱绘制。
- 图谱为空：显示“本次查询没有可展示关系”，不显示误导性的示例图。

## 验证

- 使用当前 DM8 查询结果渲染太原仓库一跳子图。
- 使用第二份 JSON 替换数据，确认 HTML 文件本身无需修改即可刷新图谱。
- 校验节点点击、关系高亮、外部 JSON 加载失败回退和移动端窄屏布局。
