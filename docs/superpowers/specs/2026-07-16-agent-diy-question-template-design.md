# 智能体 DIY 快捷问题模板设计

## 目标

为指定智能体提供独立的 DIY 欢迎区和快捷问题配置能力。页面继续使用现有 Chat 布局，保留左侧历史会话、消息列表、输入框、附件及流式回答逻辑。未启用 DIY 的智能体保持现状。

首个使用对象为“政企部运营问数智能体”。

## 用户体验

新会话尚未发送消息时，欢迎区展示已发布的快捷问题卡片。用户点击卡片后，卡片列表切换为参数填写区域。

用户填写或选择参数后点击“确认发送”，系统将参数值替换到问题模板的占位符中，生成自然语言问题，再调用现有聊天发送流程。

发送后进入当前 Chat 对话界面，新会话同步出现在左侧历史会话中。点击取消返回快捷问题卡片列表；点击新建对话后重新显示 DIY 欢迎区。

## 简化配置模型

每个快捷问题只配置以下内容：

- 卡片标题、说明、图标及排序
- 问题模板
- 模板占位符
- 每个占位符的填写方式
- 是否必填
- 选择类型的候选项

不提供脚本、条件表达式、嵌套表单或任意代码执行能力。

### 模板示例

```text
请分析 {{公司名称}} 在 {{时间范围}} 内的经营情况，
重点关注 {{分析指标}}，
并使用 {{输出格式}} 展示结果。
```

系统识别占位符后，由管理员设置：

| 占位符 | 填写方式 | 候选项 |
| --- | --- | --- |
| 公司名称 | 用户输入 | 无 |
| 时间范围 | 单选 | 近三个月、近半年、近一年 |
| 分析指标 | 单选 | 收入、客户数、项目数 |
| 输出格式 | 单选 | 文本、ECharts 柱状图、ECharts 饼图、JSON |

完成替换后的问题示例：

```text
请分析 金智维 在 近一年 内的经营情况，
重点关注 收入，
并使用 ECharts 柱状图 展示结果。
```

## 输出格式

输出格式固定为四种：

- 文本
- ECharts 柱状图
- ECharts 饼图
- JSON

文本和 JSON 使用现有 Markdown 渲染链路。柱状图和饼图复用现有 VEP/ECharts 渲染能力。系统根据选择自动附加稳定的输出协议，管理员只配置业务问题模板。

## 页面与路由

- DIY 编辑页：`/agent/:agentId/diy`
- DIY 聊天页：`/chat/diy/:agentId`
- 原聊天页：`/chat/:agentId`，行为保持不变

DIY 聊天页继续使用现有 Chat 页面结构，只在空会话欢迎区渲染 DIY 内容。

## 数据隔离

DIY 配置使用独立数据表，并通过租户和 `agentId` 唯一关联。配置包含草稿和已发布版本，聊天页面只读取已发布版本。

未配置、未发布或已停用 DIY 的智能体继续使用原欢迎页。DIY 配置失败时不阻断聊天，回退到原欢迎页。

## 发送流程

1. 用户点击快捷问题卡片。
2. 页面根据模板占位符渲染输入框或单选项。
3. 用户填写参数并点击确认发送。
4. 前端校验必填项和未替换占位符。
5. 参数值替换到模板中，生成最终自然语言问题。
6. 输出格式约束由系统追加。
7. 调用现有 `handleSend`，复用会话创建、消息保存和流式回答。
8. 发送期间禁用重复提交。

## 编辑与发布

管理员或智能体维护者可以：

- 新增、复制、编辑、删除快捷问题
- 设置卡片排序和启用状态
- 粘贴或编辑问题模板
- 为自动识别的占位符选择“用户输入”或“单选”
- 配置必填规则、默认值和候选项
- 使用模拟数据预览替换结果
- 保存草稿并发布

普通聊天用户只能填写参数和发送问题，不能修改模板。

## 验收标准

- 政企部运营问数智能体可进入独立 DIY 聊天路由。
- 左侧历史会话和当前 Chat 对话能力完整保留。
- 每张快捷问题拥有独立模板和占位符配置。
- 点击卡片后可以输入或选择参数。
- 必填项未填写时不能发送。
- 确认发送后生成的自然语言问题不存在未替换占位符。
- 文本、柱状图、饼图和 JSON 输出约束正确生效。
- 新建对话后重新展示 DIY 欢迎区。
- 其他智能体及原聊天路由行为不变。

## 非目标

- 不支持管理员编写 JavaScript。
- 不支持复杂条件模板。
- 不支持多步骤向导。
- 不支持 PDF、Word 或网页导出。
- 不修改智能体推理、工具调用或会话存储业务逻辑。
