# 商业标书追问题型

所有示例中的花括号只可替换为当前对话已有的事实。没有事实就不用该题型。

| 当前状态 | 事实前提 | 优先维度 | 可用问题形态 |
|---|---|---|---|
| 多项目检索 | 有项目标题、地区或采购方 | 项目决策 | `深入核验「{项目}」的资格、技术参数和评分办法，判断我们是否值得投` |
| 多项目检索 | 有采购方和主题 | 客户/竞争 | `查询「{采购方}」近两年与{主题}相关的采购和中标供应商，摸清历史供应商格局` |
| 多项目检索 | 有地区、时间、主题 | 机会扩展 | `在{地区}相邻市场继续筛选近期仍可参与的{主题}项目` |
| 多项目检索 | `remaining_count > 0` | 连续查看 | `继续查看当前条件下尚未展示的项目`，只能作为补充项 |
| 单项目分析 | 有项目标题 | 可行性 | `查看「{项目}」公告中的资格、技术和时间要求，列出参与缺口与待核实事项` |
| 单项目分析 | 有采购方与同类主题 | 竞争判断 | `查询「{采购方}」同类项目的中标供应商，分析竞争格局与进入机会` |
| 商机筛选完成 | 有优先项目 | 深化 | `对优先项目「{项目}」做投标可行性分析，明确建议投入、暂缓或放弃的依据` |
| 商机筛选完成 | 有已确认企业画像 | 画像匹配 | `按我已提供的业务能力、区域和案例重新筛选当前项目，说明匹配依据与缺口` |
| 采购方/市场洞察 | 有采购方、供应商或主题 | 下一步研究 | `查询「{采购方}」近两年{主题}采购，识别持续需求和主要供应商` |
| 结果不足/零结果 | 有原查询范围 | 受控调整 | `在保留{主题}和{时间范围}的前提下，将范围扩展到{相邻地区}重新筛选` |

## 质量闸门

- 同一张卡至少包含一个“决策推进”或“客户/竞争洞察”动作；不能四项都是范围调整。
- “继续查看”只能在有稳定剩余结果时出现，且不应排在首位。
- 没有企业画像时，不能写“根据我方能力已经匹配”；可建议用户提供一个会实质改变判断的画像字段，但不得把它包装成匹配结果。
- 没有公告正文、资格、技术或评分证据时，只能建议“核验/查看”，不能声称已看到内容。
- 没有截止日期证据时，不能把项目说成“临期”或“来不及”。
- 不使用“导出、订阅、监控、自动通知、联系、电话、发送、CRM、创建任务”等词作为建议动作。
- 选项之间不能等价：例如“深扒资格技术”与“分析资格技术”只能保留一个。
